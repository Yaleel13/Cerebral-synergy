# Roadmap

## Completed in phase one
- Institutional route architecture and global shell
- Threshold homepage foundation
- Metadata, robots, sitemap, not-found, loading, and error states
- Typed local content model and sample content
- Documentation and project instructions

## Deferred intentionally
- Oracle interactive systems
- User accounts/authentication
- Commerce/payment flows
- Newsletter automation
- AI chat-style assistant experiences
- Advanced WebGL or heavy realtime scenes

## Next-phase recommendations
1. Add approved brand assets and editorial content batches.
2. Introduce content workflow (MDX or CMS) once editorial process is defined.
3. Add automated tests for navigation and route smoke checks.
4. Evaluate analytics with explicit privacy posture.
