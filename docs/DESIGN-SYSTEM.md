# Design System

## Foundation
- Dark obsidian background with restrained luminous accents
- Semantic CSS tokens in `app/globals.css`
- Typography: Inter (body), Playfair Display (display)

## Principles
- Atmospheric but legible
- Strong hierarchy and readable measure
- Distinct portal identities
- Keyboard-visible focus states and reduced-motion support

## Core reusable components
- `SiteHeader`
- `MobileNav`
- `SiteFooter`
- `PortalGrid`
- `StatusMarker`
- `SectionHeading`
- `PortalPage`
