# Cerebral Synergy — Foundation Build

Phase-one foundation for **Cerebral-Synergy.com** using Next.js App Router, TypeScript, and Tailwind.

## Stack
- Next.js (App Router)
- React
- TypeScript (strict)
- Tailwind CSS
- ESLint

## Local development
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Quality checks
```bash
npm run lint
npm run build
```

## Environment
Copy `.env.example` to `.env.local` and configure real values:
- `NEXT_PUBLIC_SITE_URL`
- optional social/contact URLs
